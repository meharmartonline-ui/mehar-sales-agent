MEHAR V104 WORLD STUDIO - SETUP

1. GitHub par naya repository banayein: mehar-v104-world-studio
2. ZIP ke andar app.py, requirements.txt aur packages.txt upload karein.
3. Streamlit Community Cloud > New app > repository select karein.
4. Main file path app.py rakhein aur Deploy karein.
5. Free Edge TTS ke liye API key nahi chahiye; internet zaroori hai.
6. Groq API key sirf Translator ke liye optional hai.
7. ElevenLabs API key + Voice ID sirf Pro voice ke liye optional hain.

IMPORTANT:
- Yeh fresh V104 build hai. V102/V103 originals overwrite nahi honge.
- Sindhi free option Urdu Asad/Uzma fallback hai; asli Sindhi pronunciation guaranteed nahi.
- Baby/Old Man/Old Woman styles pitch/rate simulations hain.
- WAV conversion ke liye packages.txt mein ffmpeg install hota hai.
- SRT timings estimated sentence-level hain.
